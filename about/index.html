About This Resource

A cross-check matrix workbench built around a shared SpanBuy spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use a SpanBuy spreadsheet. It offers a way to cross-check a listing clue across three evidence surfaces — the spreadsheet row, the current source page, and specific-order evidence — using a matrix that states where each detail should be confirmed.

What this resource is not

This resource is not the official SpanBuy website, and it is not affiliated with, endorsed by, or operated by SpanBuy or Google. It is not a product database, QC certification, order tool, price system, weight calculator, or logistics tracker.

The three surfaces

Everything here keeps three surfaces apart: Spreadsheet row for discovery and shortlisting, Current source page for confirming details, and Specific-order evidence for what applies only to an actual order. No surface turns a clue into a certification.

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before relying on any listing clue.
  4. Cross-check each detail on its own surface yourself.

Cross-check example — not live data, QC approval, a quote, or a saved record.
