Listing Evidence Checklist

Check the table description, the current source page, and visible evidence as three separate passes.

Three separate passes

A listing clue has three layers, and each is checked on its own. Running them together is how a description gets mistaken for confirmed evidence.

1. The table description

What the Sheet row actually says — a name, a category, a link. Read it as a description written by someone else, not as a verified fact.

2. The current source page

What the page you opened actually shows — its title, domain, options, size, price context, and seller terms. Confirm each against your selection.

3. The visible evidence

What you can see — listing photos, warehouse photos, and any order-stage evidence. Read each at its own stage, and only for what it can show.

boundary between description, page, and evidence

The checklist

  1. Read the row as a description, and note its origin.
  2. Open the link and confirm the page identity.
  3. Re-select the option and re-read size and price in context.
  4. Separate photo stages before drawing a conclusion.
  5. List what is still unknown and keep it open.

A worked reading

  1. Description: the row names a jacket and points to a link.
  2. Page: the opened page names the jacket and matches the domain.
  3. Evidence: a listing photo shows the jacket; the size and price are re-read against the selected option.
