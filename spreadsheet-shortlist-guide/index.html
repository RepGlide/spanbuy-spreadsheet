Spreadsheet Shortlist Guide

Build a short, reviewable list from category links and Sheet clues — before you cross-check anything.

What a shortlist is

A shortlist is a small set of candidate rows you intend to check. It is not a collection of confirmed items. It is the boundary between noticing a clue and confirming it on the source page.

Start from a category

Browse a single category first. A category groups rows that belong together, which makes the list easier to keep short and consistent.

Pull candidate rows from the Sheet

Copy only the rows worth checking — the ones that match what you are looking for. Do not copy the whole Sheet into the shortlist.

Note each row’s origin

Write down where each row came from. The source check depends on knowing whether a clue came from the Sheet, a category page, or a target page.

Keep it reviewable

A shortlist you cannot finish reviewing is a list, not a shortlist. If it grows past what you can check, cut it down.

A worked reading

  1. Category: you open the Bags category and skim the grouped rows.
  2. Candidates: you copy three rows that match the bag style you want.
  3. Origin note: each row is marked with where it came from.
  4. Hand off: the shortlist is now ready for the source-page cross-check.
